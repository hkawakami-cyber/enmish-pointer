# Enmish Pointer

オンライン商談・社内MTGの画面共有を、より伝わりやすくするための**リアルタイム画面注釈アプリ**のプロトタイプです。
画面上の重要箇所をすぐに指し示し、囲み、書き込み、拡大し、注目させることで、説明の伝達精度を上げます。

> このリポジトリは **Webプロトタイプ先行** で作っています。
> 価値検証（「画面共有中に相手の視線をすぐ誘導できるか」）をブラウザで素早く回し、
> その後 macOS ネイティブ（Swift/SwiftUI）へ移行する想定です。

## 2つの成果物

| 用途 | 場所 | 説明 |
| --- | --- | --- |
| **価値検証デモ** | リポジトリ直下（`index.html`） | 疑似共有画面の上で全機能を試せる単体デモ。すぐ触れる。 |
| **実機で使う Chrome 拡張** | [`extension/`](extension/) | Meet/Zoom で**タブ共有**時に、実ページ上へ注釈できる。今日から実業務で使える。導入手順は [extension/README.md](extension/README.md)。 |

## すぐ試す

ビルド不要。ブラウザで開くだけです。

```bash
# どちらでもOK
open index.html                      # macOS
python3 -m http.server 8000          # → http://localhost:8000
```

> スクリーンショット保存（html2canvas）は `file://` でも動きますが、
> 一部ブラウザの制約を避けるためローカルサーバ経由を推奨します。

`enmish-focus-prototype.html` は CSS/JS/html2canvas を 1 ファイルに同梱した
**依存ゼロの単一ファイル版**です。ダブルクリックで開くだけ、共有にも便利です。

## 操作方法

| 操作 | ショートカット |
| --- | --- |
| アプリ ON/OFF（クイックパレット表示） | `⌘/Ctrl + ⇧ + E` |
| ペン / 矢印 / 丸囲み / 四角囲み | `⌘⇧1` 〜 `⌘⇧4` |
| スポットライト / ズーム | `⌘⇧5` / `⌘⇧6` |
| UIの表示/非表示 | `⌘⇧H` |
| 元に戻す / 全消去 | `⌘Z` / `⌘⇧⌫` |
| 注釈ツール解除・各モード終了 | `Esc` |
| スポットライトの広さ | `[` / `]` |
| ズーム倍率 | `-` / `=` |

クイックパレットが出ている間は数字キー `1`〜`6` で直接ツールを選べます。

### 基本の流れ（商談）

1. 共有画面（上部の「提案資料 / KPI表 / 商談画面」で切替）を表示
2. `⌘⇧E` で Enmish Pointer を起動 → カーソルリングが表示される
3. 矢印・丸囲みで重要箇所を指す（金額・フェーズ条件・該当列など）
4. 細かい数値はズームで拡大、結論部分はスポットライトで視線を固定
5. 細かい数値はズームで拡大、結論部分はスポットライト（横帯）で視線を固定
6. 必要なら注釈付きスクショを保存（`20260627_商談レビュー_注釈.png` 形式）
7. `Esc` で片付け、不要な注釈は全消去・1つ戻る・テキストは再クリックで修正

## 実装済みの機能（MVP）

- **カーソル強調** — リング表示、クリック波紋、色・太さ・サイズ・透明度の調整
- **注釈** — ペン / 蛍光ペン / 矢印 / 直線 / 丸囲み / 四角囲み / テキスト
- **スポットライト** — カーソル周辺以外を暗転、円/矩形、広さ調整
- **ズーム** — カーソル周辺を拡大（倍率調整）
- **カーソル形状・大きさ** — リング / 矢印 / ドット / 両方 / ハロー、大きさ 小中大
- **UIの表示/非表示** — `⌘⇧H` でツールバー等を一時的に隠して画面をすっきり
- **全消去 / 元に戻す**（テキストは再クリックで修正可能）
- **ショートカット操作** & **クイックパレット**
- **設定の自動保存** — カラーパレット・テキスト（大きさ/太さ/色）・カーソル・各種設定はブラウザに保存され次回も維持
- **カラーパレット編集** — 設定から8色を自由に変更可能
- **注釈付きスクリーンショット保存**（ファイル名自動生成）

検証用の疑似共有画面として、エンミッシュ業務でありがちな
**提案資料スライド / KPIスプレッドシート / Salesforce風商談画面** を内蔵しています。

## Webプロトタイプの制約（実機との違い）

ブラウザのサンドボックス上で動くため、以下は**実機 macOS ネイティブ版で解決**します。

- 他アプリ（Zoom / Google Meet / Keynote 等）の上に**実際にオーバーレイ描画**することはできない
  → ここでは疑似共有画面の上で挙動を再現
- OS の**グローバルショートカット**は使えない
  → `⌘/Ctrl + ⇧ + キー` をページ内で横取りして代替
- ズームは「コンテンツ自体を CSS 変形して拡大」する方式（実機はカーソル追従ズーム）

## 次フェーズ：macOS ネイティブ移行の方針

| コンポーネント | 役割 |
| --- | --- |
| Overlay Layer | 画面上に透明レイヤーを出す（`NSWindow` / `level = .screenSaver`、クリックスルー制御）|
| Drawing Engine | 線・図形・矢印の描画（本Webの `drawing.js` を Swift へ移植）|
| Cursor Tracker | グローバルなカーソル位置追跡（`CGEvent` / `NSEvent.mouseLocation`）|
| Shortcut Manager | グローバルショートカット（`CGEventTap` / Carbon HotKey）|
| Spotlight Engine | 背景暗転と注目領域表示 |
| Zoom Engine | カーソル周辺の拡大（`CGWindowListCreateImage` ベース）|
| Settings / Preset Manager | 色・太さ・ショートカット・プリセットの保存 |

必要権限：アクセシビリティ権限、画面収録権限。

### 初期プロトタイプで入れないもの

ログイン / チーム管理 / クラウド同期 / 課金 / AI要約 / 録画 / ブラウザ拡張 /
Windows対応 / 高度な図形編集 / 永続キャンバス / 複数人同時編集。
最初に検証したい価値は「画面共有中に、相手の視線をすぐ誘導できるか」に絞ります。

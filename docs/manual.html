Enmish Pointer 取扱説明 v0.5.1

Point. Annotate. Record.画面共有を、伝わる画面共有に。

商談・社内MTGの共有画面に、カーソル強調や注釈を重ねて視線を誘導。Chromeに入れて、見ているタブの上でそのまま使えます。

🎯 目玉機能  記録パック — 録画とスライドを1フォルダで自動保存

これは何

共有画面の上に描ける、消えてくれる注釈ツール

普段は端に隠れていて、必要なときだけ右端ホバーでスッと出る。終了すれば画面から完全に消えます。「邪魔にならない」が基本思想です。

左下のマーク。押すとON。
電源 ON（緑＋グロー）
起動中。ツールバーが使えます。

セットアップ

Chromeへの入れかた・差し替え

配布された zip を展開して読み込むだけ。更新版が来たら同じ手順で入れ直します。

  1. 受け取った zip を展開（フォルダができます）。
  2. Chromeで chrome://extensions を開き、右上の デベロッパーモード を ON。
  3. 「パッケージ化されていない拡張機能を読み込む」 → 展開したフォルダを選択。
  4. ツールバー右上のパズルアイコンから Enmish Pointer をピン留めすると使いやすい。
  5. 差し替え時は古い方を削除してから読み込み、設定パネル末尾の バージョン番号が新しいか確認。
使いはじめ：共有したいタブを開いて、左下の電源マーク（または ⌘⇧E）でON。あとは描くだけ。

  • 色：ツールバー下のスウォッチでワンタップ切替（4色）。明暗どちらの背景でも縁が見える二重リング。
  • 線の太さ：細 / 中 / 太 の3段階（設定）。

こまかい設定（⚙ 設定）

  • 自動表示：右端ホバーで出す（Macドック風）の ON/OFF。
  • ラベル表示：文字ラベルを消して記号だけにも。
  • バー位置 / ドック位置：左右・四隅から選択。
  • 注目の形・濃さ：帯／丸、暗さ3段階。
  • カーソルの形・大きさ・矢じりの向き。
  • 自動で消える（レーザー）：書いた線がスッと消えるモード。
  • 録画でマイクも録る / 録画中の自動スクショ。
  • 設定1・2・3：よく使う組み合わせを保存して切替。

目玉機能

記録パック — 録画とスライドを1フォルダに

ウェビナーや商談を録画すると、動画・スライド画像・メモが1つの ZIP に自動でまとまります。あとで振り返る素材がそのまま手に入る。

STEP 1
録画ボタンを押す

共有先を選ぶピッカーで、見ているタブ（スライド/ドキュメント）も選べます。

STEP 2
話す・進める

設定した間隔で、スライドが自動的に静止画として保存され続けます。

STEP 3
もう一度押して停止

動画＋スライド＋メモを ZIP にまとめて自動ダウンロード。

記録_20260628_1530.zip ├─ メモ.txt # 日時・枚数・音声 ├─ video.webm # 音声つき動画 └─ slides/ ├─ 001_00m15s.png ├─ 002_00m45s.png └─ … # 経過時間つき連番
自動スクショ間隔を OFF / 15秒 / 30秒 / 1分 から選択。1時間なら30秒で約120枚。
マイクも録るONで自分の声も画面音声とミックス（登壇録画向け／既定OFF）。
1フォルダで整理動画とスライドが時刻で対応。あとで突き合わせやすい。
設定 → 録画でマイクも録る 設定 → 録画中の自動スクショ
文字起こしについて：いまは音声つき動画を同梱するところまで。video.webm を Notta / tl;dv / Google Meetの字幕 等に渡すと文字起こしできます。

プレゼンで使う

スライドショー・全画面でも

Google スライドの発表（全画面）中でもツールバーは右端ホバーで出せます。描画やボタン操作はスライドに伝わらないので、勝手にページ送りされません。

  • Esc＋Tab起動中だけ。注釈オーバーレイをまるごと隠す／戻す。
  • 録画ピッカー「いま開いているタブ」も選べます（Macで音も録るなら “Chromeタブ” を選択）。

困ったとき

トラブルシュート

ツールバーが出てこない
画面の右端にカーソルを近づけてください（自動表示）。出ないときは左下の電源マークがON（緑）か確認。
古いバージョンが読み込まれる
chrome://extensions で一度削除してから入れ直し、設定パネル末尾の バージョン番号を確認してください。
録画ピッカーにスライドのタブが出ない
最新版（v0.5.0以降）に更新してください。「Chromeタブ」一覧に開いているタブが並びます。
録画に自分の声が入らない
設定の 「録画でマイクも録る」 を ON に。OFFのままだと画面・タブの音だけになります。
白い画面で白アイコンが見えない
ツールバーは紺色の下地つきなので明暗どちらでも見えます。注釈の色は設定で変更できます。
拡張を消したのに画面に残る
最新版では自動で消えます。残った場合はそのタブを再読み込みしてください。

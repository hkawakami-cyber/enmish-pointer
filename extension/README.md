# Enmish Focus — Chrome 拡張

ブラウザのタブ上に注釈・カーソル強調・スポットライト・ズームを重ねる、画面共有支援の Chrome 拡張（Manifest V3）です。
**Google Meet / Zoom で「このタブ」を共有する**ときに、Salesforce・Google スプレッドシート・スライド・PDF など
**ブラウザ内に表示しているページの上**へリアルタイムで注釈でき、視聴者にもそのまま見えます。

> 注釈オーバーレイは Shadow DOM に隔離しているので、開いているページの見た目を壊しません。

---

## インストール（未パッケージ拡張の読み込み）

ビルド不要です。

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** を ON
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. このリポジトリの `extension/` フォルダを選択

読み込むと、ツールバーに Enmish Focus が追加されます。

> 社内配布する場合は `extension/` を zip 化して共有し、各自が同じ手順で読み込めばOKです。
> （Chrome Web ストアに公開する場合は別途審査が必要です）

## 使い方

| 操作 | ショートカット |
| --- | --- |
| ON / OFF | `⌘⇧E`（Win: `Ctrl+Shift+E`）または拡張アイコンをクリック |
| ペン / 矢印 / 丸 / 四角 | `⌘⇧1` 〜 `⌘⇧4` |
| スポットライト / ズーム | `⌘⇧5` / `⌘⇧6` |
| プリセット切替（商談→社内→録画→デモ） | `⌘⇧0` |
| 1つ戻る / 全消去 | `Delete`（or `Backspace`）/ `⌘⇧⌫` |
| 注釈解除・各モード終了 | `Esc` |
| スポットライトの広さ / ズーム倍率 | `[` `]` / `-` `=` |

- ツールが **カーソル強調** のときはページを普通にクリック・操作できます（オーバーレイは透過）。
- ペンなどの描画ツールを選ぶと描画モードになり、ドラッグで注釈できます。
- 左バーの **営業テンプレ / KPIマーカー** をクリック → ページ上をクリックでラベルを配置。
- **📷保存** は `chrome.tabs.captureVisibleTab` で表示中タブを撮影するので、共有されている見た目そのままを
  `20260627_1305_ページ名_注釈.png` 形式で保存します。

## 機能

カーソル強調 / ペン・蛍光・矢印・横線・丸・四角・テキスト / 全消去・1つ戻る・自動消去 /
スポットライト / ズーム（表示専用）/ プリセット / 営業テンプレ・KPIマーカー / 注釈付きスクショ保存。

## 制約・既知の注意

- **ブラウザのタブ共有が前提**です。デスクトップ全体や Keynote / 別アプリの上には重ねられません
  （それには macOS ネイティブ版が必要。本リポジトリ README の移行方針を参照）。
- ズームはページ本体（`<body>`）を CSS 変形で拡大する**表示専用**機能です。`position: fixed` を多用した
  サイトでは表示が崩れる場合があるため、ズーム中は描画を無効化しています（一時的な拡大確認向け）。
- 一部サイトは独自に強いキーイベント制御を行うため、まれにショートカットが効かないことがあります。
  その場合は拡張アイコンのクリックで ON/OFF できます。
- `chrome://` などの内部ページや Chrome Web ストア上では拡張を注入できません（Chrome の仕様）。

## 構成

```
extension/
  manifest.json     権限・ショートカット・コンテンツスクリプト定義
  background.js      ON/OFF 中継 と タブキャプチャ→ダウンロード
  content.js         Shadow DOM オーバーレイ本体（UI・ツール・入力・プリセット）
  lib/drawing.js     注釈描画エンジン（Web版と共通の実装）
```
